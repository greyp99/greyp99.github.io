Code Log 3: CSS Media Queries

And now, our third codelog! We'll be talking about media queries and four of it's media features.

Media queries allow web pages to apply different styles depending on the settings of the user's device or screen design.

It works by using the @media rule to test conditions from screen width, to height and orientation. If the condition is true, the CSS inside the media query is applied.

Media queries are useful for making responsible web designs possible. Responsive design makes sure a website looks and functions well on desktops, tablets, and mobile devices.

Instead of creating seperate websites for different devices, developers can use media queries to adjust layout, font sizes, images, and navigation automatically.

Four Common Media Features

1. max-width

Max-width applies style when the screen is less than or equal to a specified value. It's commonly used to design layouts for smaller screens, especially mobile phones.

2. min-width

The min-width applies styles when screen width is greater or equal to a certain value. This helps with building layouts expanding over larger screens.

3. orientation

The orientation feature checks if the device is in portrait or landscape mode. This helps adjust layouts when a user rotates their phone or tablet.

4. prefers-color-scheme

The prefer-color-scheme checks whether the user has chosen a light or dark theme in their device. This allows developers to automatically switch between light mode and dark mode styles.

Media queries make modern responsive design possible. Using features like max-width, min-width, orientation, and prefers-color-scheme, developers can make flexible layouts that adapt to different devices and what users like.
