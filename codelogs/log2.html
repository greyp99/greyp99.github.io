Code Log 2: CSS Measuring Units

Welcome back to our second codelog! Today we're discussing measuring units, falling into two categories, relative and absolute

Absolute and Relative Lengths

Absolute Units

Absolute units have a fixed size and don't change based on screen size or surrounding elements.

They are often based on real-world measurements and fixed pixel values.

Absolute units are not usually for responsive design due to varying screen sizes.

Relative Units

Relative units are solved based on other values, from element to root font sizes, or even viewports.

These units adapt well to different screen sizes and user settings, making them ideal for responsive web design.

px and pt

px(pixels)

The px represents a pixel on your screen, and is one of the most common CSS units used, providing accurate spacing and layout.

  • It doesn't scale with user font settings
  • Helpful for proper spacing and borders
