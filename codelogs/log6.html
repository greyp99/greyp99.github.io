Code Log 6: Reference Quest

What I Looked Up:

For this Code Log, I looked up the CSS property "display". This property controls how elements appear in a webpage.

It decides if elements behave like blocks, inline elements, or more advanced layouts like flexbox and grids.

What sites did you consult?

  • W3Schools - display

  • MDN - display

  • GeeksforGeeks - display

  • freeCodeCamp - display

Differences in the Info Presented

Each site explains the "display" differently. W3Schools provides simple explanations with quick examples, but doesn't go very deep.

MDN is more detailed and technical, offering a full explanation of how display works, but it can be harder to understand.

GeeksforGeeks is more structured and example-based, but less detailed than MDN. It is useful for learning by seeing how code actually works.

Freecodecamp focuses on key values like block, inline, and inline-block, and explains how they affect layout and spacing.

Features offered in Good Code Reference Pages

  • Clear explanations of what the property does
  • Well-organized layout for easy navigation
  • Simple examples that are easy to test
  • Visual demonstrations when possible
  • Explanations of when and why it should be used
  • Advanced details for deeper understanding

Resources that stand out

MDN Stands out as the most reliable and detailed resource, although it may be difficult for beginners.

GeeksforGeeks It is useful for learning by seeing how code actually works.

W3Schools is helpful for quick learning, but it's more basic compared to the other resource but more beginner friendly
