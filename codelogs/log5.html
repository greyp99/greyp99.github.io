Code Log 5: Images

Images, one of the most important parts of web design. They help with communicate information, visually and make pages more engaging

In HTML and CSS, images can be shown in many ways depending on the purpose and layout of the image.

The two most common methods are using the HTML img tag or using a CSS background image.

Using the img Tag and Background Images

The img tag is used when the image is part of the page's actual content, like photos, illustrations or diagrams that users need to see directly in the document.

This should be inserted with an img element, images appear as its own object in the layout and can include attributes like alt, width, and height.

The CSS background-image property is used when the image is decorative or part of the page design.

Background images are applied to elements like divs or sections and they appear behind the content instead of being part of it.

Another difference is layout behavior. An img element affects the document flow like other HTML elements

while a background image stays inside the element, it's applied to and doesn't create new layout space by itself.

Other CSS Properties for Background Images

Several CSS properties can change a background images appearance. One of them being background-size.

This property focuses on how large the image appears inside the element.

One example being the use of background-size: cover; makes the image scale to covers the entire element.

Another useful property is background-repeat, which controls whether the image repeats across an element.

By default, background images repeat, but setting background-repeat: no-repeat; will display the image only once.

Another property, background-position determines where the image appears inside the element, like the center, top, or bottom.
