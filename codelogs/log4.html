Code Log 4: CSS Colors

CSS uses color to control the appearance of text, backgrounds, borders, and many other visual elements on a web page.

Adding color helps improve readability, highlight important content, and make designs more visually appealing, especially with color theory.

In CSS, colors are applied using specific properties and can be written in several different formats.

How CSS Accepts Color Values

1. Color Names

These are colors that are already defined, like red, blue, purple, yellow, and orange.

2. Hexadecimal Colors

Hex colors start with a # followed by six digits. The digits represent red, green, and blue values.

#FF5733 is a redish orange.

3. RGB Colors

RGB stands for Red, Green, and Blue. Each value ranges from 0 to 255.
