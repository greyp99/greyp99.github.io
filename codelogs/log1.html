For our fist code log, we'll be talking about HTML Semantic Elements, including Non-Semantics to see how easy the code is read or maintained.

Benefits of using Semantic Tags

One of the main benefits is due to the improved accessibility and organization when using semantic tags.

Assistive technologies and screen readers rely on semantic HTML to understand the webpage's purpose.
